# React Authentication Backend

Node.js backend implementation for user authentication (Sign-up/Login) to support React frontends. This project uses MongoDB and Mongoose for data management.

## Project Overview
* **Purpose**: Provide authentication APIs for React applications.
* **Technology**: Built with Node.js using ES Modules (.mjs).
* **Database**: MongoDB integration with Mongoose ODM.

## Directory Structure
* **controller/**: Contains logic for processing authentication requests.
* **data/**: Defines Mongoose schemas and data models.
* **db/**: Manages database connection settings.
* **middleware/**: Includes security and validation middleware.
* **router/**: Defines API routes for the application.
* **app.mjs**: Main server entry point.
* **config.mjs**: Configuration for environment and database settings.
